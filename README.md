# Screen Recorder Pro

Desktop-приложение для записи выбранной области экрана.

## Возможности

- выбор области записи;
- запись, пауза и остановка;
- глобальные горячие клавиши;
- отображение курсора;
- визуализация левого и правого клика;
- настройка FPS;
- сохранение записей в папку «Мои записи»;
- перекодирование видео в MP4/H.264 для воспроизведения в браузере.

## Стек

Python, PyQt5, OpenCV, Pillow, NumPy, PyAutoGUI, Tkinter,
keyboard, WinAPI/ctypes, FFmpeg, PyInstaller.
