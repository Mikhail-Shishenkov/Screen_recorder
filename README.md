# Screen Recorder Pro

Windows-приложение для записи выбранной области экрана в MP4/H.264. Готовая сборка запускается без установки Python и FFmpeg.

## Быстрый старт

1. Запустите `screen_recorder.exe`.
2. Нажмите «Выбрать область» и выделите экранную область.
3. Выберите режим записи и звук.
4. Нажмите «Записать». Готовые файлы находятся в папке `Мои записи` рядом с EXE.

Кнопка «Открыть папку» открывает эту папку в Проводнике. После сохранения в статусе показывается имя созданного MP4.

## Режимы записи

- `Для отправки — рекомендуется` — 30 FPS.
- `Максимальное качество` — 24 FPS.
- `Компактный размер` — 15 FPS.

## Звук

- `Без звука` — MP4 без аудиодорожки.
- `Звук компьютера` — звук приложений Windows.
- `Микрофон` — голос с выбранного input-устройства.
- `Компьютер + микрофон` — оба источника.

В режиме «Микрофон» возможно тихое попадание системного звука. Это принятый компромисс ради качественного звучания голоса.

## Горячие клавиши

- `Ctrl+1` — начать запись.
- `Ctrl+2` — пауза или продолжение.
- `Ctrl+3` — остановить запись.

## Сборка для разработчика

```powershell
venv\Scripts\python.exe -m PyInstaller --noconfirm screen_recorder.spec
```

Актуальный entrypoint — `screen_recorder.py`, актуальный PyInstaller spec — `screen_recorder.spec`. Тесты не входят в EXE и release-комплект.

## Состав release

- `screen_recorder.exe` — onefile-приложение с комплектным `ffmpeg.exe`.
- `README.md` — инструкция пользователя.
